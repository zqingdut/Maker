# 阶段照片替换说明

本站 6 个阶段的人物图已就位（`stage-01.jpg` ~ `stage-06.jpg`）。以后换照片，按下面方法替换，不用改代码。

## 文件名（固定，一一对应）

| 文件名 | 阶段 |
| --- | --- |
| `stage-01.jpg` | 01 CAMPUS 校园 2012–2016 |
| `stage-02.jpg` | 02 GAME SERVER 游戏服务器 2016–2018 |
| `stage-03.jpg` | 03 LEAD DEV 主程 2018–2019 |
| `stage-04.jpg` | 04 SKYNET 分布式架构 2019–2020 |
| `stage-05.jpg` | 05 WHITEBOARD 白板 2022–2025 |
| `stage-06.jpg` | 06 MAKER 造物者 2025–至今 |

把照片放进本文件夹（`assets/stages/`），文件名按上表，推到仓库后刷新页面即可。

## 照片要求

- 格式：JPG（推荐）或 PNG、WebP，浏览器都支持；请勿用 HEIC。
- 比例：方形 1:1 或竖版 3:4 最佳，照片会被居中裁剪铺满人物框。
- 大小：单张建议 200KB–800KB，最长边 1200px 左右就够了，太大只会拖慢加载。
- 内容：单人、正面、全身或腰部以上均可；背景越干净越好，和本站浅色底更搭。
- 如果某阶段暂时没有照片，不用放文件，该阶段会自动继续显示 SVG 剪影。

## 替换后要做的事

1. 把照片文件推到 `zqingdut/Maker` 仓库的 `assets/stages/` 目录（与本站其他文件同一个分支 `main`）。
2. GitHub Pages 会自动重新部署，等一两分钟后刷新 `https://zqingdut.github.io/Maker` 查看。
3. 若浏览器还显示旧剪影，按 Ctrl+F5 强制刷新一次。

## 备注

- 本站阶段人物图为基于本人形象的 AI 生成全身图（v2 文艺版，2026-11-11 换上）；后续如换真实照片，文件名对上直接替换即可。
- 换照片不需要改 `index.html`、`main.js` 或 `styles.css`，文件名对上就能生效。
